## Konwencje biblioteki
- Folder książki: `Books/<Autor> - <Tytuł>/`. W środku: `<ID> - Knowledge Base.md` (Obsidian) i `WORK/` (wersja czysta + części do wklejania).
- ID książki: 2–4 wielkie litery z tytułu (np. AFS). ID sekcji: `<ID>-<rozdział>.<sekcja>` są stałe i nie zmienia się ich numeracji.
- Treść jest opracowaniem własnymi słowami po polsku (bez przepisywania książki). Terminy angielskie podaje się w nawiasach.
- Oryginalny PDF trafia do `5-Raw/Books/`.
